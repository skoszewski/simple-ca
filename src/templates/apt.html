All CAs

To install the packages of this server on a Debian or Ubuntu machine, run these commands there as a user with sudo. They store the signing key of the repository in /etc/apt/keyrings/simple-ca.asc, add the repository to /etc/apt/sources.list.d/simple-ca.list, trusted with that key alone, and install the packages. Later releases come with sudo apt-get update and sudo apt-get upgrade.
